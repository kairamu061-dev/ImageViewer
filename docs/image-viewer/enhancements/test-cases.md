## 実施記録

- 2026-10-09: ユーザ実機確認。I-01（ファイル一覧の自然順ソート）は合格。I-02（兄弟フォルダ移動順）は不合格として報告され、原因調査の結果 `_natural_sort_key` を `QCollator` 実装に差し替え
- 2026-10-09: 上記修正後、I-04（日本語名の読み順）は合格。一方で `(C99)`/`(C100)` のような数字名フォルダで新たな逆順（I-05 相当）が報告され、`QCollator` の数値モードをやめて数字部分は Python int 比較、文字部分のみ `QCollator` に委ねるハイブリッド方式に変更
- 2026-10-10: ハイブリッド方式修正後、ユーザ実機確認で「問題なさそう」。I-02 / I-05 を合格に更新。I-03（隠しフォルダ除外）は個別の確認報告なし、未実施のまま残す
