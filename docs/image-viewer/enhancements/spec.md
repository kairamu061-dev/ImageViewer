# enhancements 仕様

## 機能一覧

| # | 機能名 | 説明 |
|---|--------|------|
| 1 | ドラッグパン | ズームモード時に左ボタンドラッグで画像を移動。画像端でクランプ |
| 2 | スライダージャンプ | JumpSlider でクリック位置に直接ジャンプ（ページステップ廃止）|
| 3 | 兄弟フォルダ移動 | 先頭/末尾で前後操作をすると同階層の隣フォルダへ移動 |
| 4 | コンテキストメニュー | 右クリックで「別のタブとして開く」「エクスプローラーで開く」「お気に入りに追加」|
| 5 | フォルダパネル折りたたみ | `<`/`>` ボタンでフォルダビューを開閉。状態は保存 |
| 6 | スワップボタン | 右上オーバーレイボタンでホイール/サイドボタンの動作を入れ替え |
| 7 | 自然順ソート | ファイル一覧・兄弟フォルダ一覧を数字を数値として比較する自然順でソート |

## 各機能の詳細

### ドラッグパン
- ズームモード（`_fit == False`）のみ有効
- 左ボタン押下でカーソルが ClosedHand に変わる
- オフセットは `_clamp_offset()` で画像端を超えないよう制限
- ズームイン/アウト時もクランプを再適用

### スライダージャンプ
- `JumpSlider(QSlider)` を継承し `mousePressEvent` をオーバーライド
- ハンドル外クリック時に `QStyle.sliderValueFromPosition` で値を算出して即 setValue

### 兄弟フォルダ移動
- `ImageViewerPanel._get_sibling_folder(direction)` で親フォルダの sorted されたサブフォルダリストから隣を取得
- `navigate_to_folder(Path, int)` シグナルを emit → `TabContent._on_navigate` で処理
- 兄弟がない場合は従来通り折り返し
- サブフォルダの並び順は自然順ソート（下記）。フォルダツリー（`QFileSystemModel`）の表示順と一致させている
- 隠しフォルダは移動対象から除外（`QFileInfo.isHidden()`）。フォルダツリーも隠しフォルダを表示しないため、対象の一致を保っている

### 自然順ソート
- `ImageViewerPanel._natural_sort_cmp(a, b)` が比較関数。名前を正規表現 `(\d+)` で数字部分とそれ以外の部分に分割し、数字部分は Python の `int` で数値比較、それ以外の部分は `QCollator.compare()`（大文字小文字無視・デフォルトロケール）で比較する
- `load_folder()` のファイル一覧ソート、`_get_sibling_folder()` のサブフォルダソートの両方に `functools.cmp_to_key` 経由で適用
- 例: `1,2,3,11,12,13,21,22,23` が単純な文字列ソート（`1,11,12,13,2,21,22,23,3`）にならず、数値順で並ぶ
- 数字部分を `QCollator` の数値モードに任せず自前の `int` 比較に固定しているのは、`(C99)`/`(C100)` のような名前で数値モードの大小判定が意図通りにならない事例が実機で確認されたため
- 文字部分（日本語名の読み順など）は `QCollator` に委ねているため、フォルダツリー（`QFileSystemModel`）の表示順（例: 「成」→「同」の五十音順）と一致する。単純な文字列（コードポイント）比較ではこの読み順は再現できない

### スワップボタン
- `ImageViewerPanel` の右上に 72×22px の半透明オーバーレイ QPushButton
- `checked=True` がデフォルト（ホイール=移動）
- `AppTabWidget._default_swap_mode` で全タブに同期。状態保存/復元あり

## エラーケース

| 条件 | 挙動 |
|------|------|
| 兄弟フォルダへのアクセス権なし | 移動しない（折り返し動作にフォールバック）|
| 画像が1枚のフォルダでスライダー表示 | スライダーは非表示のまま |

## 未対応ケース

- フィットモードでのドラッグ（ズームモード時のみ有効）
- タブごとの個別スワップ設定
