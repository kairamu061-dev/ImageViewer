# release テストケース

## ユニットテスト

| ID | テスト名 | 入力 / 条件 | 期待結果 | ステータス |
|----|---------|------------|---------|-----------|
| U-01 | 起動引数の解決 | `sys.argv` に存在するファイルパス / 存在しないパス / オプション(`-x`) | 最初の「存在する非オプション」パスを返す。無ければ None | [ ] |
| U-02 | 初期画像のインデックス特定 | フォルダ内の画像群と、その中の1ファイルを `initial_image` に指定 | ソート済みリスト中の該当ファイルの位置が初期表示インデックスになる | [ ] |

## インテグレーションテスト

| ID | テスト名 | 前提条件 | 手順 | 期待結果 | ステータス |
|----|---------|---------|------|---------|-----------|
| I-01 | 引数にファイルを渡して起動 | 画像の入ったフォルダ | `ImageViewer.exe <画像パス>` で起動 | その画像の親フォルダが開き、その画像が表示される | [ ] |
| I-02 | 引数にフォルダを渡して起動 | 画像の入ったフォルダ | `ImageViewer.exe <フォルダパス>` で起動 | そのフォルダが開く | [ ] |
| I-03 | セッション非破壊 | 前回のタブ構成が保存済み | 引数に画像を渡して起動→閉じる→引数なしで再起動 | 引数起動では保存されず、通常起動で元のタブ構成が復元される | [ ] |

## E2Eテスト

| ID | テスト名 | 前提条件 | 手順 | 期待結果 | ステータス |
|----|---------|---------|------|---------|-----------|
| E-01 | インストーラー生成 | Windows・PyInstaller・Inno Setup 6 導入済み | `build-installer.bat` を実行 | `dist\ImageViewer-Setup-1.0.0.exe` が生成される | [ ] |
| E-02 | インストール〜アンインストール | 生成済みインストーラー | 実行→インストール→スタートメニューから起動→アンインストール | 各段階が成功し、アンインストールで痕跡（関連付け含む）が消える | [ ] |
| E-03 | 画像ファイル関連付け | 関連付けタスクを有効にしてインストール | 画像を右クリック→プログラムから開く→画像ビューアー | その画像が表示される | [ ] |
| E-04 | 起動速度 | onedir インストール版 | 起動を数回繰り返す | 単一exe版より体感で速い（毎回のtemp展開が無い） | [ ] |

## ステータス凡例

- `[ ]` 未実施
- `[~]` 実施中
- `[x]` 合格
- `[!]` 不合格
