# release 概要

## 目的・背景

ImageViewer を一般ユーザーへ配布するための Windows パッケージングを整備する機能グループ。これまで `build.bat`（単一exe）/`build_dir.bat`（フォルダ版）でexeは作れたが、リリース配布向けの「インストーラー」が無かった。

インストーラー形式を採用する理由:
- 単一exe（`--onefile`）は毎回tempへ展開するため起動が遅く、ウイルス対策ソフトの誤検知も起きやすい
- インストーラーなら起動の速い`--onedir`版を使いつつ、スタートメニュー登録・アンインストーラ・「プログラムの追加と削除」への登録ができる
- 画像ビューアーなので、画像ファイルの関連付け（「プログラムから開く」への追加）をインストーラーで設定できる

関連付けを実際に機能させるには、アプリ側が「起動時にファイルパスを引数で受け取り、その画像を開く」必要があるため、その対応も本機能に含める。

## スコープ

### 作るもの

- Inno Setup 6 用インストーラースクリプト（`installer.iss`）
- インストーラー一括ビルド用バッチ（`build-installer.bat`：PyInstaller onedir ビルド → ISCC コンパイル）
- 起動時引数でファイル/フォルダを開くアプリ側対応（ファイル関連付けの土台）

### 作らないもの

- アプリを既定の画像ビューアーに強制設定する機能（Windows 10/11 は仕様上インストーラーから強制不可。「プログラムから開く」候補への登録にとどめる）
- 自動アップデート機構
- コード署名（証明書）。未署名のため SmartScreen 警告は出る前提
- macOS / Linux 向けパッケージング

## 制約

- 開発環境（Linuxコンテナ）には Windows・Python・PyInstaller・Inno Setup がないため、ビルド自体はユーザーの Windows 上で実行する。リポジトリにはスクリプト/設定のみを用意する
- 管理者権限を要求しない（ユーザー単位インストール）

## 完了条件

- `build-installer.bat` を Windows で実行すると `dist\ImageViewer-Setup-<version>.exe` が生成される
- インストーラーでインストール→スタートメニューから起動→アンインストールが一通り動作する
- 関連付けを有効にした場合、対応画像を「プログラムから開く」で画像ビューアーを選ぶと、その画像が表示される
