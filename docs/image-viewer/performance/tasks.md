## 依存関係

- ImageCache の変更と ThumbnailGridView / FolderOnlyModel の変更は互いに独立（並行実装済み）
- ログ追加 → 原因特定 → 遅延リトライ実装 → 再発確認 → 並列度制限・リトライ間隔延長 → 再発確認 → リトライ中断バグの発見・修正 → 再発確認 → `size()`先行呼び出し追加 → 再発確認 → 問題の性質の再認識・1:1スケールフォールバック追加 → 再発確認 → 段階的縮小カスケードに変更（この順で進めた）
